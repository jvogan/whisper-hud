# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our Pledge

We pledge to make participation in our community a harassment-free experience for everyone.

## Reporting Issues

Report conduct issues by opening a GitHub issue or contacting the maintainer directly.

## Enforcement

Maintainers will review and respond to reported issues appropriately and confidentially.
