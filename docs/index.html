WhisperHUD

macOS dictation for any text field

System-wide voice-to-text for macOS. Hold a hotkey in any app, text field, or terminal, then paste the transcription at the cursor. Use Apple Speech locally, local Whisper models, or your own cloud API keys.

Repository Quickstart
./install.sh

How it works

Three steps. Apple Speech works locally without cloud setup.

Hold the hotkey

Press Cmd+Shift+Space in the app where you want text

Speak

Talk naturally. The menu bar shows you're recording.

Release

The transcription is pasted at your cursor.

Transcription providers

Provider options available in the app.

Provider Type Setup Cost

Whisper Local Local pip install extra Free
Parakeet Local pip install extra (Apple Silicon) Free
Google Gemini Cloud API key ~$0.001/min
OpenAI Whisper Cloud API key ~$0.003–0.006/min
OpenAI Realtime Cloud Same OpenAI key Realtime pricing

Cloud costs depend on provider usage. Local providers do not use paid APIs.
