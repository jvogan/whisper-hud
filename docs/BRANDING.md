# Branding & Assets

## Banner / Social Preview

- Place the README banner at: `assets/social/readme_banner_woodblock.jpg`
- Place the Open Graph social preview at: `assets/social/og_image.jpg`
- Keep the Open Graph social preview under 1MB
- Keep width around 1200–1600px for crisp display in GitHub
- Update the README image tag if you change the file name

## Demo GIF

- Place demo GIF at: `assets/demo.gif`
- Enable the demo block in `README.md`
- Aim for <10MB to keep load times reasonable

### Capture Tips

- Record a short (8–15s) flow: hotkey → speak → paste → success HUD
- Use a clean desktop background and a large text cursor
- Keep the menu bar visible so the status icon is obvious

## App Icon / Menu Bar Icon

- Menu bar icon is defined in `whisper-hud/whisper_hud/branding.py`
- If you update icons, keep them monochrome and legible at small sizes
